HyperStrong Field Forms - phone app
====================================

What it is
- One home screen with four forms: Pre-commissioning (EPC), Cold commissioning,
  Hot commissioning and Site Job Report.
- Works on iPhone and Android, offline, with no Claude account.
- Reports are saved on the phone. When a report is done: Download PDF -> Share PDF
  (WhatsApp / Mail / Files) or Save PDF.

1. Put it online (one time)
   Upload the CONTENTS of this folder (index.html, sw.js, manifest.webmanifest and the
   icons and lib folders) to any website address that starts with https://
   Options: your company website (ask IT for a folder like https://hyperstrong.co.il/forms/),
   or a free static host such as Netlify, GitHub Pages or Cloudflare Pages.
   Do not rename or move the files. The address must be https or offline mode won't work.

2. Install on a phone
   iPhone: open the address in Safari -> Share -> Add to Home Screen -> Add.
   Android: open the address in Chrome -> menu (three dots) -> Install app.
   Open it once while online; after that it works without signal.

3. Updating later
   Replace the files on the website with a new version. Phones pick it up the next
   time the app is opened with signal.

Good to know
- Each report lives only on the phone where it was created. Finish it on that phone.
- Deleting the app or clearing the browser data deletes unsent reports. Share the PDF first.
